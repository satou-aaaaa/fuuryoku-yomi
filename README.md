# 風力階級よみ（fuuryoku-yomi）

平均風速（m/s かノット）を見て、気象庁風力階級表の風力（0〜12）を当てる1日5問の学習ゲーム。正解したら、表の備考でその風力がどの海上警報に相当するかも選ぶ。平均風速・瞬間風速の決まりの問題も出る。

遊ぶ: <https://satou-aaaaa.github.io/fuuryoku-yomi/>

- 中身は気象庁「予報用語 風」<https://www.jma.go.jp/jma/kishou/know/yougo_hp/kaze.html> の気象庁風力階級表と、「風の強さと吹き方」<https://www.jma.go.jp/jma/kishou/know/yougo_hp/kazehyo.html> の注に書いてあることだけです。
- 問題に出る風速は練習のための例で、本物の観測の記録ではありません。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。結果の「共有」を押したときだけ、その日の回の番号と各問の○×の並びが、選んだサービス（X・LINE など）に渡ります。
